# VBIC 1.3 Provenance

Source: `VA-Models/code/vbic/vacode` from
https://github.com/dwarning/VA-Models

Downloaded on 2026-06-25 from upstream commit
`ba3d04319aae2806962848bb712fd90501488d80`.

The upstream Verilog-A sources, changelog, CMC macro files, and discipline
headers are preserved in `vacode/`.

License: the vendored copy carries none. VBIC 1.3 is a CMC standard model, but
neither the VA-Models copy of `vbic_1p3.va` nor any sibling in `vacode/` ships a
license file or header; the only copyright notices in the folder are Accellera's
on `constants.vams` and `disciplines.vams`. Redistribution terms therefore have
to be established from the CMC release before this tree can be treated as
production-ready.
