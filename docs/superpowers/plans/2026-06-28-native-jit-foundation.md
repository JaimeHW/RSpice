# Native JIT Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the Cranelift native backend and all automatic interpreter fallback from Verilog-A native mode, then install the typed native-JIT foundation for x64 executable memory and instruction encoding.

**Architecture:** This is Plan 1 of the approved native JIT design. It deliberately makes `veriloga-native` full-native-or-error before adding broad codegen coverage, so failures surface as typed native JIT errors instead of silently running the bytecode VM. The new native module owns errors, ABI helpers, target selection, executable memory, x64 encoding primitives, and complete-entry-point `NativeModel` types that subsequent plans will populate from canonical OptIR.

**Tech Stack:** Rust 2024, `rspice-veriloga`, canonical IR artifacts, x86-64 machine code bytes, `windows-sys` for Windows executable memory, `libc` for Unix executable memory, Cargo feature tests.

---

## Scope Check

The approved design covers several independently testable subsystems: hard-fail native integration, Cranelift removal, canonical OptIR expansion, JIT IR, x64 code generation, register allocation, performance scoreboards, and AArch64 portability. This plan implements the first foundation slice only:

- Remove Cranelift and its fallback-oriented API surface.
- Make native mode fail closed when no complete native image can be produced.
- Add the module boundaries and tested x64 executable-memory/encoder foundation required for real codegen.
- Keep interpreter execution available in non-native builds and explicit tests, but not as a native fallback.

After this plan passes, the next plan should expand canonical OptIR into a backend-ready value graph and lower a small verified schedule into x64 code.

fn native_compile_failure_is_not_interpreter_fallback() {

        r#"
`include "disciplines.vams"

        I(p, n) <+ 1.0e-3 * V(p, n);

endmodule
"#,

fn native_new_panics_instead_of_falling_back() {
    let model = compile(
        r#"
`include "disciplines.vams"
module rjit2(p, n);
    inout p, n;
    electrical p, n;
    analog begin
        I(p, n) <+ V(p, n);
    end
endmodule
"#,
    );

    let panic = std::panic::catch_unwind(|| {
        let _ = VerilogADevice::new("R2", model, &[1, 0]);

        .downcast_ref::<String>()

        .unwrap_or("<non-string panic>");

        msg.contains("native JIT") || msg.contains("Native JIT"),
        "panic must surface native JIT failure, got: {msg}"
    );
}

use super::EvalContext;

pub type AssignmentFn = extern "C" fn(*const EvalContext, *mut f64);
pub type StampFn = extern "C" fn(*const EvalContext, *const f64) -> f64;

#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
pub struct PlanStats {
    pub assignment_entry_points: usize,
    pub stamp_value_entry_points: usize,
    pub jacobian_entry_points: usize,
}

pub struct NativeModel {
    pub num_variables: usize,
    assignment_fn: AssignmentFn,
    stamp_value_fns: Vec<StampFn>,
    jacobian_fns: Vec<Vec<StampFn>>,
    stats: PlanStats,
}

impl std::fmt::Debug for NativeModel {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("NativeModel")
            .field("num_variables", &self.num_variables)
            .field("stats", &self.stats)
            .finish()
    }
}

// Safety: NativeModel is immutable after construction. Function pointer
// lifetimes are owned by the native image that creates this table; the first
// foundation slice cannot construct NativeModel until that image owner lands.
unsafe impl Send for NativeModel {}
unsafe impl Sync for NativeModel {}

impl NativeModel {
    pub fn new_for_test(
        num_variables: usize,
        assignment_fn: AssignmentFn,
        stamp_value_fns: Vec<StampFn>,
        jacobian_fns: Vec<Vec<StampFn>>,
    ) -> Self {
        let jacobian_entry_points = jacobian_fns.iter().map(Vec::len).sum();
        let stats = PlanStats {
            assignment_entry_points: 1,
            stamp_value_entry_points: stamp_value_fns.len(),
            jacobian_entry_points,
        };
        Self {
            num_variables,
            assignment_fn,
            stamp_value_fns,
            jacobian_fns,
            stats,
        }
    }

    pub fn run_assignments(&self, ctx: &EvalContext, vars: *mut f64) {
        (self.assignment_fn)(ctx as *const EvalContext, vars);
    }

    pub fn stamp_value_fn(&self, index: usize) -> StampFn {
        self.stamp_value_fns[index]
    }

    pub fn jacobian_fn(&self, stamp: usize, entry: usize) -> StampFn {
        self.jacobian_fns[stamp][entry]
    }

    pub fn chunk_count(&self) -> usize {
        self.stats.assignment_entry_points
    }

    pub fn native_stamp_count(&self) -> usize {
        self.stats.stamp_value_entry_points
    }

    pub fn plan_stats(&self) -> PlanStats {
        self.stats
    }
}

#[cfg(test)]
mod tests {

    extern "C" fn assign_noop(_ctx: *const EvalContext, _vars: *mut f64) {}
    extern "C" fn stamp_one(_ctx: *const EvalContext, _vars: *const f64) -> f64 {

    }

    #[test]
    fn native_model_entry_points_are_not_optional() {

        assert_eq!(model.chunk_count(), 1);
        assert_eq!(model.native_stamp_count(), 1);

use smol_str::SmolStr;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Architecture {
    X64,
    AArch64,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TargetSpec {
    pub arch: Architecture,
    pub os: SmolStr,
    pub abi: SmolStr,
}

impl TargetSpec {
    pub fn host() -> Option<Self> {
        let arch = if cfg!(target_arch = "x86_64") {
            Architecture::X64
        } else if cfg!(target_arch = "aarch64") {
            Architecture::AArch64
        } else {
            return None;
        };

        let os = SmolStr::new(std::env::consts::OS);
        let abi = if cfg!(windows) {
            SmolStr::new("windows")
        } else if cfg!(unix) {
            SmolStr::new("system-v")
        } else {
            SmolStr::new("unknown")
        };

        Some(Self { arch, os, abi })
    }

    pub fn display_name(&self) -> String {
        format!("{:?}-{}-{}", self.arch, self.os, self.abi)
    }
}

//!
//! Native mode is full JIT or error. The bytecode interpreter is not a
//! fallback path when this module is asked to compile a model.

mod abi;
mod error;
mod model;
mod runtime;
mod target;
pub mod x64;

pub use model::{AssignmentFn, NativeModel, PlanStats, StampFn};

pub use target::{Architecture, TargetSpec};

use crate::codegen::CompiledModel;

pub fn compile_native(model: &CompiledModel) -> JitResult<NativeModel> {
    let target = TargetSpec::host().ok_or_else(|| JitError::UnsupportedTarget {
        target: "unknown".into(),
        reason: "host architecture is not supported".into(),

        }),
    }
}

#[cfg(windows)]
impl ExecutableMemory {
    pub fn allocate(bytes: &[u8]) -> JitResult<Self> {
        use windows_sys::Win32::System::Memory::{
            MEM_COMMIT, MEM_RELEASE, MEM_RESERVE, PAGE_EXECUTE_READ, PAGE_READWRITE, VirtualAlloc,
            VirtualFree, VirtualProtect,
        };

        if bytes.is_empty() {
            return Err(JitError::ExecutableMemory {
                detail: "cannot allocate empty executable image".into(),
            });
        }

        let ptr = unsafe {
            VirtualAlloc(
                std::ptr::null_mut(),
                bytes.len(),
                MEM_COMMIT | MEM_RESERVE,
                PAGE_READWRITE,
            )
        } as *mut u8;
        if ptr.is_null() {
            return Err(JitError::ExecutableMemory {
                detail: "VirtualAlloc returned null".into(),
            });
        }

        unsafe {
            std::ptr::copy_nonoverlapping(bytes.as_ptr(), ptr, bytes.len());
            let mut old = 0u32;
            if VirtualProtect(ptr.cast(), bytes.len(), PAGE_EXECUTE_READ, &mut old) == 0 {
                VirtualFree(ptr.cast(), 0, MEM_RELEASE);
                return Err(JitError::ExecutableMemory {
                    detail: "VirtualProtect PAGE_EXECUTE_READ failed".into(),
                });
            }
        }

        Ok(Self { ptr, len: bytes.len() })
    }
}

impl Drop for ExecutableMemory {
    fn drop(&mut self) {
        if !self.ptr.is_null() {
            unsafe {
                windows_sys::Win32::System::Memory::VirtualFree(
                    self.ptr.cast(),
                    0,
                    windows_sys::Win32::System::Memory::MEM_RELEASE,

#[cfg(unix)]
impl ExecutableMemory {
    pub fn allocate(bytes: &[u8]) -> JitResult<Self> {
        if bytes.is_empty() {
            return Err(JitError::ExecutableMemory {
                detail: "cannot allocate empty executable image".into(),
            });
        }

        let ptr = unsafe {
            libc::mmap(
                std::ptr::null_mut(),
                bytes.len(),
                libc::PROT_READ | libc::PROT_WRITE,
                libc::MAP_PRIVATE | libc::MAP_ANON,
                -1,
                0,
            )
        };
        if ptr == libc::MAP_FAILED {
            return Err(JitError::ExecutableMemory {
                detail: "mmap returned MAP_FAILED".into(),
            });
        }

        unsafe {
            std::ptr::copy_nonoverlapping(bytes.as_ptr(), ptr.cast::<u8>(), bytes.len());
            if libc::mprotect(ptr, bytes.len(), libc::PROT_READ | libc::PROT_EXEC) != 0 {
                libc::munmap(ptr, bytes.len());
                return Err(JitError::ExecutableMemory {
                    detail: "mprotect PROT_READ|PROT_EXEC failed".into(),
                });
            }
        }

        Ok(Self {
            ptr: ptr.cast::<u8>(),
            len: bytes.len(),
        })
    }
}

#[cfg(unix)]
impl Drop for ExecutableMemory {
    fn drop(&mut self) {
        if !self.ptr.is_null() {
            unsafe {
                libc::munmap(self.ptr.cast(), self.len);
            }
        }

#[cfg(feature = "native")]
fn try_native_compile(
    model: &std::sync::Arc<CompiledModel>,
) -> Result<std::sync::Arc<NativeModel>, VmError> {
    use crate::native::compile_native;
    use std::sync::{Arc, Mutex, Weak};

    type CacheEntry = (Weak<CompiledModel>, Result<Arc<NativeModel>, String>);
    static NATIVE_CACHE: Mutex<Vec<CacheEntry>> = Mutex::new(Vec::new());

    let mut cache = NATIVE_CACHE.lock().unwrap_or_else(|e| e.into_inner());
    cache.retain(|(weak, _)| weak.strong_count() > 0);
    if let Some((_, cached)) = cache
        .iter()
        .find(|(weak, _)| weak.as_ptr() == Arc::as_ptr(model))
    {
        return cached
            .clone()
            .map_err(VmError::NativeJit);
    }

    let compiled = compile_native(model.as_ref())
        .map(Arc::new)
        .map_err(|err| err.to_string());
    match &compiled {
        Ok(_) => log::info!("[JIT] Model '{}' compiled to native code", model.name),
        Err(err) => log::error!("[JIT] Model '{}' native JIT failed: {}", model.name, err),
    }
    cache.push((Arc::downgrade(model), compiled.clone()));
    compiled.map_err(VmError::NativeJit)
}
