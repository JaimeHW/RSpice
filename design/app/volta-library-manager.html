VOLTA · LIBRARY MANAGER

Library Manager — three columns, no mystery

The Library tab is where a design session starts and where its artifacts live. The grammar is Virtuoso's proven master–detail cascade — library, cell, view — but with one filter, visible metadata, and forms that refuse bad input with a sentence instead of a beep. Everything below is live: browse, filter, open the forms, trigger the validations.

03

New cell · New view — sm instances of the dialog grammar

Both forms follow volta-dialogs §01: kicker · title · field rows · footer verbs, primary on the right, Esc cancels, Enter submits. Validation answers in sentences, in place, in red — try “Create” with an empty name, or name a cell OTA5T to collide with an existing one. New view completes the §07 promise: it arrives pre-filled from the Library selection.
