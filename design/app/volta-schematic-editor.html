VOLTA · SCHEMATIC EDITOR

Canvas & document bar — the editing surface, specified

The schematic canvas has spoken VOLTA since the first cut, but it was designed in code — nothing on this surface had a drawing to answer to. This file is that drawing: the document bar grammar, the canvas vocabulary (wires, symbols, labels, junctions), selection, placement, wiring, the check overlay, hierarchy, and the two things the editor still owes its users — context menus and a reconciled empty state.

02

Canvas vocabulary — four inks on a quiet field

The canvas spends color where electricity flows. Wires get the green ink, symbols a neutral one, net labels the brass, and the accent is reserved for selection and live previews. The grid never competes: dots by default, auto-coarsening as you zoom out, gone below legibility.

InkTokenUsed for
wire--wire · 1.1 px ×zoomWires, junction dots (r 1.5 ×zoom at vertices joining ≥3 segments)
symbol--symbol · 1.3 px ×zoomDevice bodies, port flags. Bodies stroke currentColor so selection is one class flip.
net-label--net-label · mono 10.5Net names. Ports are not labels: a port flag carries a filled tip.
accent--accent · 1.5–2 px ×zoomSelection strokes, marquee, placement ghosts, wire-in-progress
warn--warn · 2 px ×zoomCross-probe net highlight (probe tool P)
GridRule
DotsOne dot per snap point, ~0.9 px. Default.
LinesHairline rules at 0.55× grid tint — quieter than dots, for dense sheets.
Auto-coarsenWhen pitch ×zoom < 9 px, step the lattice 10×, then 100×; below that, fade the grid entirely. The grid mesh is cached per pitch/style and translated on pan.
OffNo grid. Snap still applies — the grid is a display, not the snap.

All ship today. Zoom is cursor-centered at 1.1× per wheel notch; pan is middle-drag or Shift+drag.

04

Placement — the ghost commits on click

Arming a part (palette, place strip, or a key) attaches its ghost to the cursor at 55% accent. The ghost snaps to grid, R rotates it in quarter turns, H/Y mirror, click drops an instance and keeps the tool armed, Esc disarms. The status bar narrates: “Placing resistor — click to drop, R rotates, Esc finishes.”

LIVE — MOVE · R ROTATES · CLICK DROPS · ESC ENDS
hover the canvas to arm a resistor ghost

Ships today, including the live narration. The place strip at the rail's foot (volta-schematic-rail.html) recalls the last part with one click.

05

Wiring — click to bend, right-click to let go

W arms the wire tool. Each click pins a vertex; the segment chasing the cursor draws at 60% accent until pinned. Right-click or Esc finishes the run. Junction dots appear only where three or more segments actually meet — corners stay clean.

LIVE — CLICK TO PIN · RIGHT-CLICK FINISHES
click anywhere to start a wire · land on the existing wire to make a junction
RuleDetail
verticesUser-pinned. The tool never reroutes a pinned segment — the path you click is the path you get.
start dotThe first vertex draws a 4 px ×zoom accent dot while the run is open.
junctionsCreated where a run ends on existing copper, and at any vertex joining ≥3 segments.
labelsN arms a net label; dropping it on copper names the net (brass ink, §02).
06

Checks overlay — findings live where the fault is

Ctrl+E runs the electrical rule checks. Every finding with a location pins a screen-constant triangle badge to it — 7 px half-extent, never scaling with zoom, filled by severity. Hover explains and proposes the fix. Findings without a location (global checks) report to the console and the pill only.

07

Hierarchy — descend in place, ascend by breadcrumb

Double-click a cell instance — or select it and press Shift+E — to descend. The canvas swaps to the master's schematic, the breadcrumb grows one hop, and the rail's nameplate mirrors the occurrence path. U ascends one level; clicking any breadcrumb hop pops straight back to it. Edits made while descended land in the master cell — every instance of it everywhere.

StateBreadcrumb

Ships today. Deliberate scope note: descend is Shift+E, not Virtuoso's bare E — E is properties here and overloading it was rejected. A read-only banner for descents into read-only-library masters is spec: amber strip under the docbar, “Read-only — ‹PDK› masters cannot be edited”, with a “Copy to editable library…” action.

08

Context menus — the third hand spec

Today right-click only finishes a wire. That stays — when the wire tool is live, right-click means “done.” In every other state, right-click should open the menu for what's under the cursor. Every item is a shortcut the menu teaches: nothing appears here that lacks a keyboard or menubar route.
