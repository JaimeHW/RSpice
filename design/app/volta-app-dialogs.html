The app-level surfaces: the keyboard-first command palette, the dialog that themes the instrument, the card that teaches the keys, and the one that says what build you're holding. volta-dialogs.html deferred these as “mechanical ports of the same shape” — true for About, an understatement for the rest. All four are live below.

01

Command palette — every verb, three keystrokes away

Ctrl+K floats a 520 px panel 96 px from the top, query focused. It searches the whole command set (47 verbs, minus Cancel and the palette itself) with the shipped ranking — prefix beats word-start beats substring beats subsequence — and shows at most 12 rows; the remainder becomes “N more — keep typing.” This demo runs the real algorithm: try pl, then pre, then zf (a subsequence).

03

Keyboard shortcuts — the deck, searchable

F1. One scrolling card, category headers, description left, keycaps right. The dialog once drew seven categories and silently dropped the commands that had none — run/stop, checks, zoom, tab switching, searches, hierarchy. Simulation and Navigation now complete the deck, and a filter narrows it, because nobody reads 47 unfiltered rows.

04

About — what build, what engine, what license

Small dialog, five facts, two verbs. The license line spells out the menubar tier, and Copy diagnostics puts version, build hash, engine, license, and OS/arch on the clipboard — the first thing support asks for and the last thing users can find.
