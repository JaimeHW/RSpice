As tuned

Implementation: the editor is a real text buffer (egui TextEdit with a layouter) over the same parser the engine uses — diagnostics come from Netlist::parse spans, not a second grammar. Tuner rows are generated from .param statements with range annotations (* @tune 5u..60u); "live" mode debounces at one in-flight run, reusing the warm circuit via the AC symbolic cache. Diff bars compare against the last run's buffer snapshot, not the file on disk.
