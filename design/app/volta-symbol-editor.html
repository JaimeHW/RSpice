VOLTA · SYMBOL EDITOR

Symbol editor — the cell's public face, finally editable

A symbol is a contract: what a cell looks like on every sheet that places it, and which pins it promises. Today symbol views say “no editor yet.” This spec is that editor — one surface that edits writable symbols, inspects PDK symbols behind the same amber gate the schematic uses, and enforces the terminal-grid law the shipped artwork was drawn under. Nothing here is built; every section is the contract to build against.

01

One surface, two postures

PostureRule
editWritable-library symbols open editable: pins place and move, body tools draw, labels anchor. Edits mark the view dirty exactly like the schematic; undo shares the same transaction grammar.
inspectRead-only-library (PDK) symbols open behind the same amber banner the schematic uses — “Read-only — '⟨lib⟩' masters cannot be edited” — with the same “Copy to editable library…” way out. Every edit path refuses with the same console line. One gate, everywhere.
routingLibrary browser: symbol views double-click open here (their meta stops saying “no editor yet”). The docbar reads lib · CELL · symbol; the workspace tab stays Schematic-family — symbols are design views, not a sixth tab.
02

Canvas law — the terminal grid is load-bearing

The schematic's wires can only land where the symbol promises terminals. So this canvas renders the 40-unit terminal lattice heavier than the schematic's working grid, and the one inviolable rule is mechanical, not advisory:

ElementRule
terminal grid40-unit lattice, dots one weight up from the schematic grid. Pins snap to it, period — there is no off-grid pin, not even with snap “off”.
body geometryFree — vertices snap to the quarter-grid (10 units) for drawability, and the shipped artwork's sub-grid curves remain representable. The body is drawing; the pins are contract.
originAccent cross at the reference point — the coordinate the schematic places and rotates around. Draggable; defaults to the bbox center snapped to grid.
bboxFaint dashed rectangle, auto-fitted to geometry plus pin stubs; defines the selection halo and label-avoidance zone on sheets.
inkThe artwork law, enforced by construction: bodies stroke at 1.3 in the symbol ink; the only fills the tools can produce are arrows, dots, and port tips. There is no fill bucket.
03

Pins — the contract, checked like ERC

The pins rail lists the schematic view's ports — the symbol cannot invent a pin the cell doesn't have, or silently drop one it does. Placement is the only degree of freedom, and the docbar pill reports the contract the way the schematic's ERC pill reports topology.

ElementRule
anatomyTerminal pad (open square on the grid point, wire ink) · stub into the body · mono name riding the stub. The pad is what wires hit; it renders only in the editor, never on sheets.
placementP arms the next unplaced pin (rail order); click a grid point on or outside the bbox to land it. Click an existing pin to move it. The rail row and the canvas pad select together.
directionin · out · inout · passive, inherited from the port; shown in the rail, drawn as the stub's arrowhead for in/out when “direction marks” is on.
pill states“PINS match schematic” ok · “PINS N unplaced” err · “PINS N orphaned” err (symbol has a pin the schematic dropped — offer delete) · “PINS no schematic” idle (symbol-only cells: the rail becomes editable and the symbol IS the contract).
checksPin findings join the design checks: UnplacedPin (error), OrphanedPin (error), PinOffGrid (impossible by construction, checked anyway for imported artwork — error). Console rows jump here like every other finding.
04

Body tools — five, and no fill bucket

ToolKeyRule
polylineWClick to pin vertices, right-click/Esc finishes — the schematic's wire gesture, drawing symbol ink instead of copper.
circle · arcC · ACenter-then-radius; arc adds start/sweep handles. Sources, gates, and bubbles are circles — these two cover the shipped set.
arrowDThe filled triangle glyph (MOSFET/BJT convention), placed on a segment and flippable with H/Y.
dotOThe 1.7-radius filled dot (bulk ties, junction marks).
selectS/EscClick, marquee, move; R rotates the selection in quarter turns around the origin; Del deletes. Undo wraps every gesture.

Deliberately absent: rectangles-as-primitives (a polyline closes), text-as-geometry (labels are anchors, §05), and any fill tool — the artwork law has no filled regions, and the editor cannot produce what the law forbids.

05

Labels — anchors, not text

AnchorRule
@nameWhere the instance name (X1, M2…) lands when placed. Brass ink in the editor; the sheet substitutes the real name. Default: above the bbox, left-aligned.
@valueWhere the value/model string lands. Default: below the bbox. Both anchors drag freely; the sheet's smart label placement starts from them and still avoids collisions.
preview tileThe as-placed tile (hero, bottom-right) renders the symbol at sheet zoom with real label substitution — the volta-symbols judging discipline, permanently installed in the editor.

RuleDetail

07

Keymap

GroupBindings
toolsS select · P place next pin · W polyline · C circle · A arc · D arrow · O dot · Esc cancel
transformR rotate selection · H/Y mirror (and flip an arrow)
sharedZoom, pan, undo/redo, clipboard, F fit, Ctrl+E checks — identical to the schematic; no symbol-only chords to relearn.

Single letters reuse the schematic's letters where the muscle memory transfers (W draws a run, C is round, D is the triangle) — the two surfaces are one editor in two postures, and the hands should agree.
